Get Airlock

The web app is the fastest way in on every device. Windows users who want a real app that launches at startup can use the installer.

Windows

Download Airlock for Windows

One-click installer, about 90 MB. Installs to your user profile (no admin rights needed) and adds Start-menu and Desktop shortcuts. Windows SmartScreen may warn that the publisher is unknown because the app isn't code-signed yet; choose More info → Run anyway. Sign in with an email code; Google sign-in inside the desktop app is coming.

The installer is being uploaded — check back shortly, or use the web app below in the meantime.

Mac

Open the app in Safari and choose File → Add to Dock (macOS 14 or later), or in Chrome click Install in the address bar. It runs in its own window with its own Dock icon.

Android

Open the app in Chrome or Firefox → menu → Add to Home screen.

iPhone / iPad

Open the app in Safari → Share → Add to Home Screen. Other iPhone browsers can't install web apps.

Any browser

Or skip installing: airlock.neworbitdigital.com/app works anywhere and remembers your sign-in.
